Courtesy of NERVOSYS, LLC · Publication contact: Dr. Adam Erickson · https://nervosys.ai

All PDFs use US Letter. Body pages have **0.75-inch margins** on each side, for a **7.0 × 9.5-inch** live area. Running headers/footers use the margin bands. The illustrated cover of the Field Guide remains full bleed but has a 0.75-inch safe text inset.

All three publications share the same NERVOSYS defense-tech palette, Inter typography, masthead, banners, and publication controls. Each PDF has an editable HTML source and a companion Typst source. PDF exports use HTML/CSS rendered with WeasyPrint; Typst compilation is not independently verified.

To rebuild, run `sh build_pdfs.sh` in this folder after installing WeasyPrint. The final stylesheet is `PRINT_MARGINS_VERSION_14_5.css`, whose rules are embedded in each HTML document for portability. See `PUBLICATION_QA_VERSION_14_5.json` for validation results.
