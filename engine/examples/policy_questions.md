# Example public questions (do not include individual student details)

**Administrator:** What evidence is needed to evaluate gunfire detection without obstructing safe egress?

**Educator:** What does the guidance say about evaluating uncorroborated threat allegations while preserving student rights?

**Policymaker:** Which Washington school security duties are legally conditional, and how should we track implementation without claiming automatic compliance?

**Technology lead:** What tests should be completed before a connected door controller or alert system is deployed?

**Community partner:** How can we improve voluntary secure storage without constructing an ownership registry?

**Auditor:** Explain T12 and trace its relationship to cybersecurity controls and rights guardrails.
