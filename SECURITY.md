# Security and responsible disclosure

This repository publishes general school-safety recommendations. **Never publish sensitive facility-specific security details** or information about children or employees, including non-public threat assessments, camera layouts, access-control information, emergency credentials, student records, personal contact information, or precise weak points.

Do **not** open a public GitHub issue containing security details. Use the repository's private GitHub security-advisory reporting mechanism if enabled; otherwise contact the maintainers through a pre-existing private channel. Avoid including sensitive details until a private disclosure channel is established.

For changes involving new source material, run `python scripts/privacy_check.py`, review file metadata and embedded images manually, and obtain necessary publication and licensing permissions. A scanner is not a substitute for human review.
